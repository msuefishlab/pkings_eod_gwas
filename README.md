# The genomic basis of electric signal diversity: analysis code

Code for Gallant, Picq, Koenig, Ngoua Aba'a, Nzigou & Mipounga, *The Genomic Basis of Electric Signal Diversity*
(Nature Communications, 2026; DOI to be added). The study maps the genetic basis of a repeatedly evolved change in the
electric organ discharge (EOD) of the African weakly electric fish *Paramormyrops kingsleyae*: the presence or
absence of the initial phase P0, which separates triphasic (TP) from biphasic (BP) waveforms.

The repository holds the scripts behind every analysis reported in the paper and its Supplementary Information. It
does not hold sequence data, call sets or results. Those are either public (see [Data](#data)) or regenerated by the
pipeline.

## Layout

Each module in `code/` has its own README with inputs, steps and outputs.

| Module | What it does | Paper |
|---|---|---|
| `00_common` | Shared helpers; builds the sample sheets from Supplementary Data S1 | — |
| `01_Terra` | Read alignment and joint genotyping (GATK best practices, run on Terra) | Methods: variant calling |
| `02_Phenotyping` | EOD waveform processing and P0 scoring (MATLAB, R) | Fig. 1, Data S2 |
| `03_VCF_QC_Filter` | Variant filtering, call-set QC, reference-bias check | Methods; Table S3 |
| `04_Phylogenomics` | Gene trees, species tree, concordance, ancestral-state reconstruction | Fig. 2B, Figs. S2–S3 |
| `05_PopGen` | Windowed π, F_ST, d_XY, Tajima's D | Fig. S1 |
| `06_Association` | GEMMA association scans and permutation thresholds | Fig. 3A, Table S1 |
| `07_Phasing` | SHAPEIT4 phasing | Methods; Fig. S4 |
| `08_Peak_Analysis` | Peak annotation, LD and percent variance explained | Fig. 3B–C |
| `09_RNASeq` | Electric organ RNA-seq (STAR, RSEM, DESeq2) | Fig. 4A |
| `10_Introgression` | Dsuite D statistics, f4-ratio, f_dM | Figs. S5–S6, Table S4, Data S7 |
| `11_Drift_vs_Selection` | Sweep scans, demographic models, drift simulations, local ancestry | Fig. S7, Tables S5–S6, Supplementary Note |
| `12_Historical_Ne` | SMC++ effective population size | Fig. S9 |
| `13_Structure` | ADMIXTURE | Fig. S8 |
| `14_Wobble_Analysis` | Mixed-waveform ("wobble") fish: peak haplotypes, P0 scans, power simulation | Fig. S4, Table S2, Supplementary Note |
| `15_TFBS_Scan` | Transcription-factor binding-site changes at peak variants | Data S4–S6 |
| `16_IHC` | SPTBN4 immunohistochemistry quantification | Fig. 4B |

`images/` holds the container definitions. `config.env` holds every shared path and file name. The code calls the
mixed-waveform fish of the paper "Wobble".

## Data

The pipeline starts from public data. None of it is copied into this repository.

| Data | Source | Place it at |
|---|---|---|
| Whole-genome resequencing reads (305 fish) and new electric organ RNA-seq | NCBI SRA, BioProject PRJNA1218444. Per-sample accessions are in Supplementary Data S1. | fetched by `01_Terra` and `09_RNASeq` |
| Earlier electric organ RNA-seq | SRA BioProjects PRJNA417677 and PRJNA573805 | `09_RNASeq` |
| Reference genome and annotation | GenBank JBLIQM000000000 (BioProject PRJNA1218457); RefSeq GCF_048594095.1 | `input_data/00_Reference_Genome/` (see its README) |
| Specimen table | Supplementary Data S1 (`SupplementalDataS1_Fish_Specimens.xlsx`) | `input_data/01_Terra/data_model/` |
| EOD plots | Supplementary Data S2 | — (raw EOD recordings are not distributed; `02_Phenotyping` documents the method) |
| Mormyrid EOD phenotypes | Supplementary Data S3 (`SupplementalDataS3_MormyridEODs.xlsx`) | `input_data/04_Phylogenomics/` |

Download the Supplementary Data files from the paper's page. Then build the sample sheets the code reads:

```bash
Rscript code/00_common/make_sample_sheets.R    # needs R with readxl
```

Small derived inputs (sample subsets and phenotype codings for each comparison, population lists, region lists) are
in `input_data/`. Immunohistochemistry images (`16_IHC`) are not distributed.

## Running

The analyses ran on a SLURM cluster with Singularity, except the R Markdown reports and figure scripts.

1. Build the containers in `images/` (see `images/README.md`) and place the `.sif` files in `images/`.
2. Edit the site-specific block at the top of `config.env`: scratch space, cloud bucket and the IHC image directory.
3. From the repository root, `source config.env` before running any step.
4. Edit the `#SBATCH` headers (account, partition, memory) for your cluster.
5. Run the modules in order. `01_Terra` and `03_VCF_QC_Filter` produce the call sets everything else uses.
   `07_Phasing` produces the phased call set used by `08`, `11`, `14` and `15`. Each module README gives the order
   within the module.

Outputs go to `output_data/<module>/`, which git ignores.
